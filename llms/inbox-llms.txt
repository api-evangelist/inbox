# Inbox

> Inbox is an API Evangelist index of email and inbox-oriented API platforms that developers use to send, receive, parse, route, schedule, and verify email messages. The index focuses on transactional and conversational email providers exposing programmatic access to message lifecycle, deliverability, and inbox automation primitives. Inbox is an editorial index maintained by API Evangelist — it is not a company and it operates no API of its own. Every API listed below is published and operated by the third-party company named in the entry.

## APIs indexed

- [Mailgun Email API](https://www.mailgun.com/): Programmable email API for sending, receiving, tracking, and validating email at scale — messages, domains, suppressions, mailing lists, webhooks, inbound routes, event streams, and inbox placement testing. Operated by Mailgun (Sinch). Base: https://api.mailgun.net/v3
- [Nylas Email API](https://www.nylas.com/products/email-api/): Unified REST API for email, calendar, contacts, and scheduling across Google, Microsoft, iCloud, and IMAP — read, send, and thread messages, manage folders and labels, handle attachments, and subscribe to webhook notifications. Operated by Nylas. Base: https://api.us.nylas.com/v3
